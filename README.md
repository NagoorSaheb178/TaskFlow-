# TaskFlow – Team Task Management App

## 🎯 Overview

TaskFlow is a modern **full‑stack task management** web application built with **Next.js 16**, **React**, and **Tailwind CSS**. It provides a clean, premium UI that works beautifully on both **mobile** and **desktop** devices for **admin** and **member** roles.

- **Kanban board** with *To Do*, *In Progress*, and *Done* columns.
- **Responsive navigation** – a sliding drawer on mobile and a fixed sidebar on larger screens.
- **Authentication** via **next‑auth** (credentials provider).
- **CRUD** for tasks, projects, and users through a simple API layer.
- **Role‑based UI** – admins can create tasks, projects, and manage users; members have read‑only access.

## 🎨 UI / Design Notes

- The **Sidebar** component (`src/components/Sidebar.tsx`) uses a **mobile‑first** approach:
  - On screens `< md` a hamburger button appears; clicking it opens a full‑screen overlay drawer.
  - On `md` + screens the classic fixed sidebar is displayed.
- **Tailwind utilities** provide smooth hover effects, transitions, and responsive spacing.
- Colors are chosen from the **Material‑3** palette (primary, secondary, surface) to give a premium look.
- **Accessibility** – interactive elements have `aria-label`s, focus styles, and proper semantics.

## 🛡️ Authentication & Roles

- **Admin** users (role = `"Admin"`) see extra UI controls:
  - *Add New Task* button on the Kanban board.
  - Ability to delete tasks.
- **Member** users can only view tasks and change status.
- Session handling is wrapped by `Providers.tsx` using `SessionProvider`.

- **Extend API** – replace the mock routes in `src/app/api/` with real database calls (e.g., Prisma, MongoDB) as needed.
